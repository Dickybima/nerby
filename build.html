03 · For developers

Call the endpoint directly.

The endpoint is plain JSON-RPC over HTTP (MCP Streamable HTTP, stateless). You can use it from any language without an MCP library.

List the tools
curl -s https://www.nerbyprotocol.xyz/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
Call a tool
curl -s https://www.nerbyprotocol.xyz/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"get_gas_price","arguments":{"network":"base"}}}'
