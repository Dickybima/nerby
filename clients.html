Clients

Connect once.
Use it everywhere.

Setup takes about a minute in each app. Pick the client you use and follow its steps.

00 · The endpoint

One URL for every client.

Everything below comes down to pasting this address into your AI app. There is no key to request and nothing to sign up for.

Endpoint · MCP

01 · Claude

Claude apps and Claude Code.

Claude on web and desktop

Add a custom connector

  1. Open Settings → Connectors.
  2. Choose Add custom connector.
  3. Name it Nerby Protocol and paste the endpoint URL.
  4. Start a chat and enable the connector.

Custom connectors depend on your Claude plan.

Claude Code

One command

Run this in your terminal, then ask Claude Code a chain question.

claude mcp add --transport http nerby https://www.nerbyprotocol.xyz/mcp

02 · Editors

Cursor and VS Code.

Both read a small JSON file. Create it if it does not exist, then reload the editor.

Cursor · .cursor/mcp.json

Cursor

{
  "mcpServers": {
    "nerby": {
      "url": "https://www.nerbyprotocol.xyz/mcp"
    }
  }
}
VS Code · .vscode/mcp.json

VS Code

{
  "servers": {
    "nerby": {
      "type": "http",
      "url": "https://www.nerbyprotocol.xyz/mcp"
    }
  }
}

03 · ChatGPT and others

Any client that speaks MCP.

ChatGPT

Custom connector

In ChatGPT, turn on developer mode under Settings → Connectors, create a new connector and paste the endpoint URL. No authentication is needed.

Availability depends on your ChatGPT plan and workspace settings.

Zed and local-only clients

Bridge with mcp-remote

Clients that only launch local servers can reach the endpoint through the mcp-remote bridge. Use this as the server command:

npx -y mcp-remote https://www.nerbyprotocol.xyz/mcp

04 · First prompts

Things to try once connected.

Read

Check a wallet

“What is the ETH and USDC balance of vitalik.eth’s address 0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045 on Ethereum?”

Inspect

Explain a transaction

“Look up this transaction hash on Base and tell me what happened, who paid and how much the fee was.”

Compare

Gas across chains

“Compare the current gas price on Ethereum, Base, Arbitrum and Robinhood Chain.”

Understand

Read a contract

“Look up the verified source of this contract on Ethereum and explain what its functions do.”

Deploy

Create a token

“Prepare a token called Demo Coin, symbol DEMO, with a supply of 1,000,000 on Robinhood Chain from my address, and give me the deploy link.”

Preview

Dry-run a transfer

“Simulate sending 0.05 ETH from my address to this one on Optimism. Would it succeed, and what would it cost?”
