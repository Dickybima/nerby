01 · Read

Balances, tokens, blocks, transactions, event logs, storage slots and contract calls, fetched live the moment you ask. Answers come from the chain itself rather than from a guess.

Connect once.
Use it everywhere.

02 · Clients

Nerby Protocol speaks MCP, the open standard that Claude, ChatGPT, Cursor, VS Code and Zed use for tools. Add the endpoint a single time as a custom MCP server and that client can reach the chain.

See it first.
Sign it yourself.

03 · Control

Any transaction or deployment is dry-run on current state first: whether it succeeds, why it would revert and what it costs. Nerby Protocol holds no keys. You sign in your own wallet.

From a prompt
to a live contract.

04 · Build

Describe a token or bring your own Solidity. Nerby Protocol compiles it, estimates the fee and hands you a deploy link. You review the source and sign in your own wallet.

Many networks,
a single door.

05 · Live

Robinhood Chain, Ethereum, Base, Arbitrum, Optimism, Polygon, BNB Chain and four more are live today. Each network gets the same tools and the same endpoint.
